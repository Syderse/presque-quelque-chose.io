On rend une façade sobre (type + titre) ; au clic, un petit script vanilla injecte l'iframe réelle (ou, pour redcircle, le script + le conteneur du lecteur). Paramètres : type youtube | spotify | acast | redcircle (obligatoire) id identifiant (vidéo YouTube, ou épisode redcircle pour la classe) src URL complète (iframe, ou src du script redcircle) title libellé affiché sur la façade height hauteur en px pour les lecteurs audio (défaut selon le type) Aucune fonte/CDN ajouté, CSP inchangée.
