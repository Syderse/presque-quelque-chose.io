# SYSTEM_MANIFEST.md

## 1. Architecture Overview
This system operates on a **Hugo Extended** kernel running inside a containerized environment. The primary objective is to maximize information density while maintaining a strict Catppuccin color palette.

### Core Components:
* **Kernel:** Hugo v0.120+ (Extended)
* **Style:** TailwindCSS v4 (JIT Mode)
* **Scripting:** Vanilla JS (ES6+)

## 2. Deployment Protocols
The deployment pipeline triggers automatically upon commit to the `main` branch. Assets are minified, fingerprinted, and served via CDN.

> WARN: Ensure strict adherence to the "Horror Vacui" design principle. Empty space is an error.
