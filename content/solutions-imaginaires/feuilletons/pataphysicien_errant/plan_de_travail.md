# Plan de travail

## Phase 1 - Genese (en cours)

Le terreau. Accumuler la matiere brute sans se soucier de la forme finale.

- [x] Note fondatrice : coucher l'intuition du projet
- [x] Catalogue d'evenements (30+), les plus divers possible
- [x] Inventaire des types de sources/mediums narratifs
- [x] Cartographie des lieux (inspires du reel, a renommer)
- [x] Ebauche de chronologie sur 2+ siecles
- [x] Galerie de personnages recurrents
- [x] Bibliographie : auteurs a pasticher + oeuvres proches en esprit
- [ ] Enrichir les evenements jusqu'a 50, puis 80, puis 100
- [ ] Pour chaque evenement, noter en une ligne le potentiel sonore (ce qu'on entendrait a la radio)
- [ ] Choisir 5 a 8 evenements "pilotes" parmi les plus excitants

## Phase 2 - Exercices de style

Comme La Fontaine : se preparer a ecrire, pas encore ecrire. Des gammes.

- [ ] Ecrire 5 pastiches courts (1-2 pages) d'auteurs differents, sur des sujets libres, pour se faire la main
- [ ] Ecrire 3 scenes de dialogue pur (format script radio) pour trouver le rythme de la parole
- [ ] Ecrire 2 paysages sonores (description technique : quels sons, quelle duree, quels enchainements) sans aucun dialogue
- [ ] Combiner : ecrire un script radio complet (3-5 min) qui melange parole, silence et son
- [ ] Identifier les 3-4 voix stylistiques qui reviennent naturellement (les garder, les nommer)

## Phase 3 - Architecture narrative

La structure macro. Le point faible revendique : c'est la qu'il faut s'acharner.

- [ ] Definir les "arcs longs" : quels fils rouges traversent les siecles ? (le personnage du chroniqueur, la rumeur qui enfle, les groupes de chercheurs)
- [ ] Decouper la chronologie en 4-6 epoques, chacune avec sa couleur propre
- [ ] Pour chaque epoque, choisir 4-6 evenements et attribuer source + style
- [ ] Creer un tableau croise : evenement / source / lieu / epoque / style / personnages recurrents impliques
- [ ] Definir l'ordre de lecture/ecoute : chronologique ? par source ? par lieu ? alternance ?
- [ ] Planifier les "noeuds" : les moments ou des sources se recoupent, ou un personnage recurrent fait le lien entre deux epoques

## Phase 4 - Ecriture des pilotes

Passer a l'acte sur un echantillon.

- [ ] Ecrire 3-5 episodes pilotes complets (format script radio)
- [ ] Les tester a voix haute, seul ou avec des complices
- [ ] Enregistrer au moins un episode en conditions reelles (voix, sons, montage)
- [ ] Evaluer : est-ce que ca fonctionne ? qu'est-ce qui tient, qu'est-ce qui tombe ?
- [ ] Ajuster le format (duree, ratio parole/son, nombre de voix)

## Phase 5 - Production

- [ ] Constituer une equipe minimale (voix, son, peut-etre musique)
- [ ] Definir un calendrier de publication (mensuel ? bimensuel ?)
- [ ] Choisir un support de diffusion (podcast, webradio, autre)
- [ ] Ecrire et enregistrer la premiere saison (5-10 episodes ?)

## Notes libres

- Ne pas oublier : chaque episode doit pouvoir se lire/ecouter independamment. Le feuilleton est un bonus, pas un prerequis.
- La Fontaine se preparait. C'est normal de se preparer. Mais a un moment, il faut aussi se lancer.
- Le ridicule est un registre, pas un defaut. Les traces dans un manuel de montage de meubles, le brouillon de haiku : ce sont les meilleures idees.
